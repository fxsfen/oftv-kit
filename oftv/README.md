# Монтаж OFTV через Claude — инструкция для монтажёра

## Один раз: установка (~30 мин, почти всё делает Claude)

GitHub-аккаунт не нужен: старший монтажёр пришлёт **ссылку-ключ** вида
`https://<ключ>@github.com/fxsfen/oftv-kit.git` (только скачивание, никому её не пересылай).

1. Установи **Claude Desktop** (claude.ai/download) и войди в аккаунт (лучше тариф Max).
2. В Claude открой вкладку **Code**, выбери любую папку (например «Документы») и вставь это сообщение,
   подставив свою ссылку:

   > Установи OFTV-kit. Если нет git — поставь через winget (Git.Git). Склонируй <ССЫЛКА> в папку OpenMontage
   > в моей домашней папке, запусти там `powershell -ExecutionPolicy Bypass -File oftv/install.ps1`,
   > потом `oftv/tools/doctor.py`. Скопируй `oftv/claude-settings.json` в `.claude/settings.json`, если его нет.
   > Отвечай по-русски.

   Дальше Claude сделает всё сам (~30 мин), иногда Windows попросит нажать «Да».
3. Когда напишет «READY», открой в Claude папку `OpenMontage` — дальше работай только в ней.
   Если что-то сломалось — напиши там **`/ustanovka`**, он проверит и починит.

Компьютер: Windows 10/11, 16 ГБ ОЗУ (лучше 32), 50+ ГБ свободно на диске C:, интернет.

## Каждый день: монтаж

Скинь папку с видео в **Загрузки** и напиши Claude одну команду:

| Что нужно | Что писать |
|---|---|
| Обычное видео | `/bazovoe daisyyyli` |
| Пачку моделей сразу | `/bazovoe монтаж пн` |
| Первое видео новой модели (поп-апы, шоу) | `/pervoe lia_life` |
| Перемонтаж: два видео → одно | `/peremontazh mia_tesh` |
| Правки / OFTV отклонил | `/pravki daisyyyli музыка слишком громкая` |
| Забрать новые правила от команды | `/obnovit` |

**Как называть папки:**
- одно видео → папка = тег модели: `Загрузки\daisyyyli\` (внутри все клипы, голосовые, фото, музыка);
- пачка → одна общая папка, внутри по папке на модель: `Загрузки\монтаж пн\daisyyyli\`,
  `Загрузки\монтаж пн\lia_life\` … Общую музыку можно положить в `Загрузки\монтаж пн\music\`.

Claude один раз задаст вопросы по всей пачке (тег, музыка, спорные места), потом монтирует сам.
Готовое лежит на рабочем столе: **`OFTV готово\<модель> <дата>\`** — видео 2K, 2 обложки, название и описание.

Можно писать и обычными словами: «смонтируй папку монтаж пн», «переделай видео лии, модель просит убрать кадр на 1:20».

## Если что-то не так
- Напиши Claude, что именно не так, своими словами — он исправит.
- Компьютер не выключать и не усыплять во время рендера.
- Не удаляй и не переименовывай исходники в Загрузках, пока видео не принято.
